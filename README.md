# DevOps By Nabawy

Free collection of DevOps guidebooks, cheat sheets, and companion courses.
Live at <https://eslamnabawy.github.io/DevOps-By-Nabawy/>.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Build

Static prerendered output for GitHub Pages lands in `dist/client`:

```sh
npm run build
```
